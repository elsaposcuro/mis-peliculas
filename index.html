Configurar búsqueda (TMDb)

Para buscar películas y series necesitás una API key gratuita de TMDb:

  1. Creá una cuenta gratis en themoviedb.org (sin tarjeta)
  2. Andá a tu perfil → Configuración → API y generá una "API Key (v3 auth)"
  3. Pegala acá abajo y guardá
